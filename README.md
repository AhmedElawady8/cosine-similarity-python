# Cosine Similarity and Cosine Distance in Python



This Jupyter notebook explains cosine similarity and cosine distance using simple vector examples and a small document comparison exercise.



## What the notebook covers



\- The formulas and interpretation of both cosine measures.

\- Cosine similarity for aligned, nearly aligned, and perpendicular vectors.

\- Document comparison using a table of manually entered counts for the terms `iphone` and `galaxy`.

\- A pairwise cosine similarity matrix for three documents and individual cosine distance examples.



## Run locally



The examples are included in the notebook and require no external data.



```bash

python -m pip install notebook pandas scikit-learn

jupyter notebook cosine\_similarity.ipynb

```



Open \[cosine\_similarity.ipynb](./cosine\_similarity.ipynb) and run the cells in order.
